# AI Image Caption Generator

An elegant, modern AI Image Caption Generator built with React, Vite, and powered by Anthropic's Claude Vision AI.

## Features
* **Vision AI**: Generates 5 high-quality, human-like captions using Claude.
* **Multiple Tones**: Choose between Descriptive, Poetic, Social Media, Professional, Storytelling, and Minimal tones.
* **Stateless Metadata Extraction**: Extracts scene type, mood, and visual tags.
* **Modern UI**: Smooth animations, dark mode, file drag-and-drop interface.

## Installation & Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/rohitmoran/image-caption-generator.git
   cd image-caption-generator
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
